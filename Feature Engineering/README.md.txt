# Titanic Dataset: Feature Engineering

### Transforming Raw Data into Meaningful Features

## Project Overview

Feature Engineering is an important step in Data Science and Machine Learning. It involves transforming existing data into meaningful features that can help uncover hidden patterns and improve model performance.

In this project, I performed Feature Engineering on the Titanic dataset using Python and Pandas. The objective was to create meaningful features from existing passenger information and explore their relationship with passenger survival.

## Objectives

- Create meaningful features from existing dataset columns
- Calculate passenger family size
- Categorize passengers based on family size
- Calculate individual fare per family member
- Explore relationships between engineered features and survival
- Visualize patterns using statistical plots
